# severny-pirog
# Северный пирог

Учебный одностраничный сайт школьного буфета.

🔗 [Посмотреть сайт](https://iamschikov.github.io/severny-pirog/)

## Стек
HTML, CSS, JavaScript

## Что умеет
- Рисует меню из шести позиций на основе массива данных
- Фильтрует блюда на сладкие и солёные, сортирует по цене
- Показывает состав пирога в модальном окне
- Считает общую сумму выбранных позиций
- Переключает тёмную тему и сохраняет выбор пользователя
- Отображает картинку `pie.svg` через относительный путь

## Роль ИИ
- Подготовлена картинка `pie.svg` по образцу из учебного материала, пути проверены вручную
